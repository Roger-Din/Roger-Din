# Hi, I'm Roger 👋

I am a Computer Science and Data Science student based in Sydney, Australia.

I enjoy building systems that solve practical problems—from graph algorithms and database applications to autonomous agents and developer tools. My work focuses on understanding how software behaves beneath the interface, not just making it run.

## Selected Projects

- **Autonomous Treasure Hunt Agent**  
  An intelligent agent that explores an unknown environment, builds an internal map, collects tools, crosses obstacles, retrieves treasure, and returns home.

- **University Timetable Planner**  
  A Python and PostgreSQL application for querying course data, validating enrolment rules, and producing structured academic plans.

- **Road Network Navigator**  
  A graph-based navigation system written in C, supporting route calculation and time-dependent road conditions.

- **Huffman Coding Toolkit**  
  A lossless text compression and decompression system built with binary trees and frequency-based encoding.

- **MyGit**  
  A simplified version-control system implemented in Python, including staging, commits, history inspection, and file-state tracking.

- **MyGive**  
  A POSIX shell assignment-management system supporting submissions, automated testing, marking, status inspection, and retrieval.
